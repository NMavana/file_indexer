# Code of Conduct

## Our pledge

We are committed to making participation in File Indexer welcoming, respectful, and harassment-free for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good faith.
- Focus on the issue, not the person.
- Accept feedback and differing viewpoints.
- Protect other users' privacy and sensitive information.

## Unacceptable behavior

Harassment, discrimination, personal attacks, doxxing, threats, and publishing private information without consent are not acceptable.

## Enforcement

Project maintainers may edit, remove, or close contributions that violate this code of conduct. Serious or repeated violations may result in a temporary or permanent ban from project spaces.

## Contact

Please report concerns privately to the project maintainers rather than posting sensitive details publicly.
